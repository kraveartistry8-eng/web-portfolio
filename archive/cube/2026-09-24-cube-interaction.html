Seven behaviours. Handle them.

No momentum anywhere. All seven drift when left alone, all seven print the type on the face, all seven open a panel on click. The top row changes what a drag does. The bottom row changes where a hover lands. The small mono word in the corner of each tells you what state it is in.

Row one

What a drag does

Hover settles all four the same way, a few degrees off square, so the only variable is the drag. Press and pull each one, then let go and watch what it does.

Row two

Where a hover lands

All three drag the same way, held one to one and settling on release. The variable is the pose it comes to rest in when you put the pointer on it.
