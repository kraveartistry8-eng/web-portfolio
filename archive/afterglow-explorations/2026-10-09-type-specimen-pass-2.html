Three more pairings, read off what is actually in use

Each pairing sets the wordmark, a hero line from the brief, and a paragraph of the voice as it is written in voice-tone.md, all on the real #080808 ground. The scale under each one is the same in all three, so the faces are the only variable.

The scale is a ratio, not a list. Base 16px, ratio 1.25, every step derived. The scale_measured check recomputes each step from the ratio and fails any size that was chosen by eye instead.

Build cost. All six faces are in Shopify's font library, checked against the library table in the theme settings documentation on 9 October 2026. None needs a webfont in assets/. The cost of a two-face system is one added font_picker in config/settings_schema.json, since the theme ships with exactly one.

The thing worth knowing before you pick. Fonts In Use is an archive of commercial type. Almost every pairing in its fashion and packaging sections uses faces that must be licensed and self-hosted, which is a different order of cost from anything on this page. The section at the foot names them and says why none is set here.

Where this came from. Pass 1 offered three pairings chosen from Shopify's library on brand reasoning alone. Aaron pointed at fontsinuse.com and asked which pairings there would suit Afterglow. These three are read off that archive: two built from faces it actually uses that are also in the library, and one control.

Considered and set aside

What the archive actually runs on

Fonts In Use is overwhelmingly a commercial type archive. Its fashion and packaging sections are built on Italian Plate No2, Px Grotesk, Chiswick Grotesque, Apercu, Degular, Familjen Grotesk, Gotham, Self Modern and Berlingske. None is in Shopify's library and none is free. Each would need a paid webfont licence, a file in assets, an @font-face rule and a schema change, which is a different order of cost from the pairings above, not a different taste.

Why none of them is shown on this page

Rendering a commercial face here would mean licensing it first, and setting a free lookalike in its place would misrepresent what you would actually be buying. If one of those names is the direction, say so and the next pass prices it properly rather than approximating it.

Bebas Neue, Cooper Black, Helvetica

The only broadly available faces in the packaging archive. Bebas Neue is a condensed poster capital, Cooper Black is a 1922 novelty, and Helvetica carries no hour at all. All three are available and none suits a brand whose voice is unhurried and physical.
