Afterglow · working artifact · pass 1 · 9 October 2026

Three pairings, one display face and one body face

Each pairing sets the wordmark, a hero line from the brief, and a paragraph of the voice as it is written in voice-tone.md, all on the real #080808 ground. The scale under each one is the same in all three, so the faces are the only variable.

The scale is a ratio, not a list. Base 16px, ratio 1.25, every step derived. The scale_measured check recomputes each step from the ratio and fails any size that was chosen by eye instead.

Build cost. All six faces are in Shopify's font library, checked against the library table in the theme settings documentation on 9 October 2026. None needs a webfont in assets/. The cost of a two-face system is one added font_picker in config/settings_schema.json, since the theme ships with exactly one.

Where this came from. The colour system is settled: ramp E, with stage two named After gold. Type is the second of the two picks the spec defers to a visual artifact, because neither can be settled in prose.

What came next. Aaron pointed at fontsinuse.com and asked which pairings there would suit Afterglow. Pass 2 reads three off that archive, and says plainly what the archive's own faces would cost.

Pairing A

Instrument Serif / Inter

Instrument Serif shopify_library · Inter shopify_library · no webfont in assets, one added font_picker in the schema

AFTERGLOW

The light only ever deepens, never brightens.

Unhurried and physical. It names heat, light, breath and skin. It describes a sequence, because the product is a sequence. Certain without pushing. The brand does not argue for itself. It assumes you will understand it if you are shown it in the right order.

Editorial and high contrast. The thin strokes go very thin on a void ground, which is either the point or the problem. Inter underneath says nothing at all, which lets the display carry the whole voice.

Considered and set aside

Spectral

Absent from Shopify's font library. It would have to ship as a webfont in assets with its own @font-face rule, so it costs a build change the other six do not.

Cormorant Garamond

Absent from the library for the same reason, and its hairlines are the thinnest of any candidate considered, which is the worst case on a void ground.
